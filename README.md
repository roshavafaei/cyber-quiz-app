# QuizForge 🔐

A modern cyber security quiz app built with  HTML, CSS and vanilla JavaScript.

## 🌐 Live Demo

https://quizzforge.netlify.app


## 📁 Repository

https://github.com/roshavafaei/cyber-quiz-app


## 🚀 Features

- 10 timed questions (30 seconds each)
- Instant feedback (correct / incorrect)
- Real-time score tracking
- Smooth animations and interactive UI
- Netlify (Deployment)


## 🧠 Topics Covered

- Web security (XSS, SQL Injection)
- Networking basics
- Cryptography fundamentals
- Security concepts and threats


## 🛠 Tech Stack

- HTML5
- CSS3 (Custom Properties, Animations)
- Vanilla JavaScript
